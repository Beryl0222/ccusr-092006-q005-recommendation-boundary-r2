# 推荐兴趣边界自主管理

本项目用于整理推荐兴趣边界自主管理领域中的事件名称、交换字段与脱敏样例，方便业务、运营和研发人员在同一套术语下讨论后续服务。资料只包含领域约定，不包含真实个人信息、生产连接或外部账号，也不承担推荐模型训练——推荐引擎只通过这里定义的稳定契约与本服务交互。

## 事件种类

| 事件 | 含义与约束 |
| --- | --- |
| `SIGNAL_OBSERVED` | 分别记录观看、收藏、主动搜索、负反馈、运营活动五类信号；负反馈必须标注作用于单条作品（`item`）、主题（`topic`）还是整个账号（`account`） |
| `INTEREST_INFERRED` | 写入或更新人类化可读的兴趣条目，必须带来源信号与有效期；敏感主题不得仅凭偶然停留（`accidental_dwell`）写入长期画像 |
| `BOUNDARY_CHANGED` | 用户调整条目、重置或限制某类推断、配置多样性探索；重置与限制必须同时注销别名组，旧策略不得通过别名再次恢复 |
| `PROFILE_ACCESSED` | 推荐引擎每次取用画像都登记策略版本与用途；广告与自然推荐明确分流（`ads` 用途只能走 `ads` 通道）；探索用途必须携带用户配置的频率与内容安全边界 |
| `RECOMMENDATION_EXPLAINED` | 客服视角的解释记录，列出一次推荐用到的信号及各自是否仍有效，可据此区分兴趣拓展与商业投放 |
| `WITHDRAWAL_PROPAGATED` | 撤回请求向所有活跃设备与缓存传播，记录别名注销与缓存过期时间 |
| `WITHDRAWAL_VERIFIED` | 验证撤回在所有活跃设备确认、缓存过期后不再参与新决策 |

## 目录

- `src/`：事件种类、交换字段与领域约束的校验。
- `data/sample.json`：用于核对资料格式的虚构事件。
- `data/samples/`：每种事件与关键分支的虚构样例。
- `tests/`：保证样例与领域约定保持一致。

## 本地核对

```bash
python3 -m unittest discover -s tests
```
